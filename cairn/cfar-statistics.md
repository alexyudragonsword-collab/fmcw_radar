# CA-CFAR 在相关的格上(P2 #0,0.2.3)

> 当前真相。代码 `processing/cfarstats.py`,测试 `tests/test_cfarstats.py`,复现 `python examples/06_cfar_curves.py`。

## 结论

- 白噪声经窗 w、零填充 p 倍的 FFT,相隔 k 个填充格的两格复相关是 w² 的谱:R(k) = Σ w² e^{−j2πkn/(Np)} / Σ w²,功率相关 |R|²,两维相乘。
  Hann 的整数格:R(1) = −2/3、R(2) = 1/6、其余为 0;一次独立观测沿一维占 L = Σ_k |R(k)|² = p·N·Σw⁴/(Σw²)² 个填充格(Hann:1.944 p,矩形:p)。
- **训练集的有效格数** N_eff = N² / Σ_ij ρ_ij。默认(Hann / Hann、距离填充 ×4、guard 2 + train 8):416 格只值 **33.4** 格,阈值比设计的抖 → 单看这一项 Pfa 1e-4 → **2.7e-4**。
- **被测格与训练格的相关** c(训练格对被测格功率相关的均值)。guard 按填充格数:×4 填充下 guard 2 = **0.5 个距离格**,最近的训练格还在被测格自己的主瓣上,c = 0.0151。
  噪声峰把自己的阈值抬高:α → α′ = α(1 − c)/(1 − αc) = 10.7(原 9.31)→ 单看这一项 Pfa → **2.6e-5**。
- 两项合起来一阶式 (1 + α′/N_eff)^(−N_eff) = 9.5e-5;**精确值 1.02e-4**——默认配置下两个效应几乎抵消,设计 Pfa 碰巧是对的。
  guard 加到 8 格(2 个距离格)c → 0,Pfa 反而升到 1.8e-4(只剩训练集那一项)。guard 表见示例 06。
- **精确式**:X > α·mean(Y) 等价于 Hermitian 型 Q = |x|² − (α/N)Σ|y_i|² > 0;z = (x, y) 联合高斯、协方差 Σ(上面的相关),Q 同分布于 Σ_k λ_k E_k
  (λ 是 Σ^{1/2} A Σ^{1/2} 的特征值,A = diag(1, −α/N, …),E_k 独立指数)。A 只有一个正元 → 只有一个正特征值 λ₊ → **Pfa = Π_j 1/(1 + |λ_j|/λ₊)**。
  独立格时退化为教科书的 (1 + α/N)^(−N)(测试逐位核到 1e-6)。
- 一帧的虚警格数期望 = 格数 × 每格 Pfa(期望对相关无感);相关改的是它们成团出现(1e-4 时每团 2.5 格,1e-2 时 4.5 格)和一帧有多少独立观测:
  IF 带内 51200 格(32 chirp)= **3385** 次独立观测,期望 5.2 个虚警格 ≈ 2 团。

## 核对的数

- 白噪声经同样的窗与填充(120 张图,1.54e7 格):设计 1e-2 / 1e-3 / 1e-4 实测 1.044e-2 / 1.033e-3 / 1.062e-4(示例 06;35262 / 5093 / 641 团),精确式 1.039e-2 / 1.036e-3 / 1.021e-4;
  换一个 seed 是 1.040e-2 / 1.026e-3 / 1.018e-4。
  另五组(矩形无填充、Hann 无填充、guard 8、矩形 ×4、两维都 ×4)比值 0.89–1.03(样本量按团数算,最少 387 团 ±5 %)。guard 0 / 2 / 4 / 8 格:Pfa 9.2e-6 / 1.02e-4 / 1.70e-4 / 1.79e-4。
- 时域引擎纯噪声帧(6 帧,6.1e5 个带内格,正负拍频都算、避开砖墙边沿):1.022e-2 / 9.57e-4 / 9.2e-5,对精确式 0.98 / 0.92 / 0.90(1420 / 186 / 25 团)。

## 坑

- **坑(contains:"按独立格算的闭式是上界"是错的)**:里程碑 2 看到 64000 格 4 个虚警(6.3e-5 对 1e-4)就写了"闭式是上界"。实际训练集相关让 Pfa **升**,
  被测格相关让它**降**,方向取决于 guard;那 4 个格是 ~2 团,期望 5.2 格,纯属抽样。
- **坑(contains:一阶式在 guard 落在主瓣里时崩)**:两维都 ×4 填充、guard 2 时 αc = 0.9,一阶式给 7e-10,实测 9.7e-6(差四个量级);
  矩匹配的 Gamma 积分好一些但仍差 5 倍;特征值精确式 9.3e-6。所以报的数用精确式,一阶式只留作两项各自的解释。
- **坑(contains:训练窗比多普勒轴还宽)**:8 个 chirp、21 格宽的训练窗沿多普勒轴绕 2.6 圈,把被测格自己也收进训练集:c = 0.088,设计 1e-4 实际 1.4e-6。
  相关函数按 n·pad 循环,所以闭式自动带着这个绕回(测试核过 1e-2 档)。TDM-MIMO 每 TX 只有 4 个 chirp 时同理。帧短于训练窗时 CFAR 的 Pfa 没有意义。
- **坑(contains:聚成团的计数,样本量是团数)**:虚警格成团,相对误差按 1/√团数 估,不是 1/√格数;测试的容差就这么写的。
- **没做的(ROADMAP P1 #3)**:MIMO 的图是 K 个虚拟通道的非相干和(Gamma(K) 不是指数),仍用单通道的阈值因子:K = 8 时 Pfa 1e-4 → 1.2e-23,
  阈值比需要的高 5.1 dB(9.7 对 4.6 dB)。

# CA-CFAR 在相关的格上(P2 #0,0.2.3;K-look、裁剪、Pd 与鬼目标 0.2.4)

> 当前真相。代码 `processing/cfarstats.py`,测试 `tests/test_cfarstats.py`,复现 `python examples/06_cfar_curves.py`。

## 结论

- 白噪声经窗 w、零填充 p 倍的 FFT,相隔 k 个填充格的两格复相关是 w² 的谱:R(k) = Σ w² e^{−j2πkn/(Np)} / Σ w²,功率相关 |R|²,两维相乘。
  Hann 的整数格:R(1) = −2/3、R(2) = 1/6、其余为 0;一次独立观测沿一维占 L = Σ_k |R(k)|² = p·N·Σw⁴/(Σw²)² 个填充格(Hann:1.944 p,矩形:p)。
- **训练集的有效格数** N_eff = N² / Σ_ij ρ_ij。默认(Hann / Hann、距离填充 ×4、guard 2 + train 8):416 格只值 **33.4** 格,阈值比设计的抖 → 单看这一项 Pfa 1e-4 → **2.7e-4**。
- **被测格与训练格的相关** c(训练格对被测格功率相关的均值)。guard 按填充格数:×4 填充下 guard 2 = **0.5 个距离格**,最近的训练格还在被测格自己的主瓣上,c = 0.0151。
  噪声峰把自己的阈值抬高:α → α′ = α(1 − c)/(1 − αc) = 10.7(原 9.31)→ 单看这一项 Pfa → **2.6e-5**。
- 两项合起来一阶式 (1 + α′/N_eff)^(−N_eff) = 9.5e-5;**精确值 1.02e-4**——默认配置下两个效应几乎抵消,设计 Pfa 碰巧是对的。
  guard 加到 8 格(2 个距离格)c → 0,Pfa 反而升到 1.77e-4(只剩训练集那一项)。guard 表见示例 06。
- **精确式**:X > α·mean(Y) 等价于 Hermitian 型 Q = |x|² − (α/N)Σ|y_i|² > 0;z = (x, y) 联合高斯、协方差 Σ(上面的相关),Q 同分布于 Σ_k λ_k E_k
  (λ 是 Σ^{1/2} A Σ^{1/2} 的特征值,A = diag(1, −α/N, …),E_k 独立指数)。A 只有一个正元 → 只有一个正特征值 λ₊ → **Pfa = Π_j 1/(1 + |λ_j|/λ₊)**。
  独立格时退化为教科书的 (1 + α/N)^(−N)(测试逐位核到 1e-6)。
- 一帧的虚警格数期望 = 格数 × 每格 Pfa(期望对相关无感);相关改的是它们成团出现(1e-4 时每团 2.5 格,1e-2 时 4.5 格)和一帧有多少独立观测:
  IF 带内 51200 格(32 chirp)= **3385** 次独立观测,期望 5.2 个虚警格 ≈ 2 团。

## K 个 look 的非相干和(MIMO 图,0.2.4)

- `_process_cube` 的图是 K = n_tx × n_rx 个虚拟通道的非相干和,格功率是 Gamma(K)。被测格 /(被测格 + 训练和)~ Beta(K, K·N),阈值因子取它的分位数
  (`threshold_factor(n, pfa, n_looks)`;K = 1 逐位是原来的闭式):K = 8、N = 416、1e-4 → α = 2.88(4.6 dB),单通道因子 9.31(9.7 dB)。
- **坑(contains:单通道阈值因子用在非相干和上)**:修之前 Pfa 是 1.2e-23,阈值高 5.1 dB;指纹里 `mimo_2x4_coupled` 的 39 dB 目标 **0 个检测格**(修后 12 个)。
- 精确式推广:每个特征值重复 K 次,Q 的矩母函数只有一个 K 阶正极点,Pfa 是它的留数(g 的各阶导数有闭式,F = e^g 的导数用 Leibniz 递推)。
  独立格时 K = 1 / 2 / 8 / 16 × Pfa 1e-2 / 1e-4 / 1e-6 都回到设计值(1e-5 内);相关格 K = 8 对蒙卡 1.01 / 1.02。

## 检测概率与目标自漏(0.2.4)

- 被测格里的稳态目标也落在自己的训练格里:单音的窗响应 |W(k)|²/|W(0)|² 在训练格上的均值 c_w = 0.0062(同一个半格 guard)。
  `cfar_pd`:阈值 α(c_w S + c|n|² + (1 − c)G),对被测格噪声配方后是非中心卡方对 Gamma 阈值的一维积分(Gauss–Laguerre 48 点)。S = 0 时回到一阶 Pfa。
- 默认图上 Pd 0.9 要 **12.24 dB**(已知噪底 11.75 dB):CFAR 损失 0.49 dB,含自漏。独立格 N = 16 时回到里程碑 2 的 1.35 dB。
  对注入单音的蒙卡:N_eff ≥ 24 时 ±0.03;很短的帧(N_eff 5–12)±0.07(ROADMAP P1 #3)。2 × 4 MIMO、每 TX 16 chirp:每 look 5.0 dB 到 Pd 0.9。

## TDC 鬼目标进虚警账(P1 #1(c),0.2.4)

- 鬼目标是确定性的、每个 chirp 相同,所以和目标同多普勒、相干累积:当作 SNR = 目标每 look SNR + 电平(dBc)的稳态目标,`cfar_pd` 给它的 Pd,
  视野内的求和就是每帧"既不是目标也不是噪声"的检测数(`StatResult.cfar["ghosts"]`、`ghost_detections_per_frame`,报表有表)。
- 32 chirp、5 m:人体(每 look 47.1 dB)鬼目标 SNR +1.6 dB,合计 0.03 个 / 帧(时域 4 帧 0 个);0 dBsm 2.78(时域 8 帧平均 2.00);+4 dBsm 4.78(4.12);
  车 5.00(5.00,视野内 5 个全中)。陡段上鬼目标电平差 1 dB,Pd 差 0.15(ROADMAP P1 #1(c))。
